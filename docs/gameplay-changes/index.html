EVs/IVs

These systems have been dramatically simplified. EVs are now rewarded uniformly for each foe fainted. 2 EVs in each stat to each participant. This incentivizes some amount of individual growth throughout gameplay but significantly cuts out any kind of grind or FOMO normally attached to EVs. IVs no longer roll 0-31. By default, IVs are always 31. You can opt to have some randomization to IVs if you disable the associated setting.
